# 🚀 Fitpulse

Premium digital storefront engineered for high-peformance fitness consulting.

## 🛠️ Tech Stack

* **Core Framework:** [React.js](https://react.dev) (Functional Components, Hooks)
* **Build Tooling:** [Vite](https://vite.dev) (Ultra-fast HMR and bundling compiler)
* **Styling Engine:** [Tailwind CSS](https://tailwindcss.com)
* **State & Icons:** React Context API / Lucide React

## 🚀 Core Features

* ** Navbar:** Features dynamic window scrolling trackers.

* ** Pricing:** Toggle Calculation Engine: Built with localized memory states that seamlessly adjust treatment investment rates across tiered components from monthly to into annual terms without page refreshes.


* ** SocialFaq:** Action Accordion: Uses precise layouts with DOM traversal sibling hooks tracking variable states to mnage smooth opening and closing animations cleanly.


## 🏃‍♂️ Quick Start (Local Development)

### 📋 Prerequisites
Ensure you have [Node.js](https://nodejs.org) (v18 or higher) installed on your machine.

### 🔧 Installation Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project root directory:**
   ```bash
   cd Fitpulse
   ```

3. **Install all required dependencies:**
   ```bash
   npm install
   ```

4. **Launch the local development environment:**
   ```bash
   npm run dev
   ```
   *The application will boot locally at `http://localhost:5173`.*
